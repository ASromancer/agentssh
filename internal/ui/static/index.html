Duyệt

Cấu hình trên đĩa (~/.config/ostiary/hosts.toml / rules.toml) đã thay đổi và chưa được duyệt: mọi yêu cầu của agent đang bị chặn. Mở hai file đó để kiểm tra thay đổi (host mới, allow/deny, quy tắc), rồi mới bấm "Đọc lại cấu hình" ở màn hình Host.

Không có yêu cầu nào đang chờ

Khi agent chạy lệnh cần xác nhận, yêu cầu sẽ hiện ở đây ngay lập tức và bạn cũng nhận được thông báo trên máy.
